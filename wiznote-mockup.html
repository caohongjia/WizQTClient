📌 概述

本文总结了使用 Qt 框架开发跨平台桌面应用的一些经验和技巧。WizNote 作为一款成熟的跨平台笔记软件，其源代码中有很多值得借鉴的设计模式。

核心理念： 一次编写，到处运行。Qt 的信号槽机制、事件系统、样式表，让跨平台开发变得优雅而高效。

🏗️ 主窗口架构

WizNote 的主窗口采用经典的三栏布局，通过 QSplitter 实现可调节的分栏：

  • 左侧：WizCategoryView —— 树形分类导航
  • 中间：WizDocumentListView —— 文档列表
  • 右侧：WizDocumentView —— 使用 WebEngine 渲染的富文本编辑器

🎨 样式系统

利用 Qt 样式表 (QSS) 实现浅色/深色主题切换：

// 在 WizMainWindow 中应用主题
void WizMainWindow::applyTheme() {
    if (isDarkMode()) {
        setStyleSheet("background-color:#1e1e1e; color:#ddd;");
    }
}

🔧 关键组件

以下是一些代码中出现的核心组件类：

  • WizShadowWindow —— 自定义带阴影的窗口基类
  • WizTitleBar —— 自定义标题栏
  • WizSplitter —— 增强版分栏器
  • WizSearchView —— 全局搜索组件
  • WizEditorToolBar —— 编辑器工具栏
  • WizUserInfoWidget —— 用户信息组件

💡 开发建议

  1. 充分利用 Qt Creator 的跨平台编译工具链
  2. 使用 Q_OS_WIN / Q_OS_MAC / Q_OS_LINUX 条件编译
  3. 自定义控件继承 QWidget 并使用信号槽通信
  4. 善用 Q_PROPERTY 实现 QML/JS 桥接
  5. 考虑 HiDPI 适配，使用 WizSmartScaleUI() 缩放
